Installation ​

Paperback is a modern, ad-free reading app for Apple devices that supports manga, comics, novels, and more. It delivers a smooth, distraction-free experience with features such as offline reading, iCloud sync, and progress tracking.

Apple Device Required

Paperback is an app for Apple devices only, for Android and Windows we recommend Mihon and Suwayomi respectively.

By default, Paperback comes with no built-in content. To read anything, you will need to install extensions that connect to reading sources.

Inkdex is a community-driven project that develops and maintains these extensions.

Extension Registry ​

The extension registry contains all extensions maintained by the Inkdex community.

Click the installation button below to add it to your Paperback app.

Install Registry
Install Manually
  1. Open the Paperback app.
  2. Tap the cog to open Settings.
  3. Tap Extensions.
  4. Tap + and choose Source Repository.
  5. Paste https://inkdex.github.io/extensions/0.9/stable into the Repository Base URL field.

The registry is hosted on GitHub and can be found in our extensions repository. It is completely automated and for more info you can join our Discord server and ask us about it!
